    <div className="home-faq-list">
      <Accordion title="Do I need to change my build tools?"><p>No. The bundled shell executor runs your existing commands. Add native plugins project by project where they fit your workflow.</p></Accordion>
      <Accordion title="Do all projects need a tsconfig?"><p>No. Project discovery uses <code>project.json</code>. Package manifests and JavaScript imports contribute dependencies too. TypeScript configs provide aliases and compiler output information when available.</p></Accordion>
      <Accordion title="Does Isox schedule dependency builds or cache task results?"><p>These features are on the <a href="https://github.com/isox-sh/isox/blob/main/ROADMAP.md">roadmap</a>. Today, build prerequisites explicitly before their consumers. Isox caches project definitions and on-demand dependency analysis separately; tasks still run on each invocation. See <a href="/docs/configuration#discovery-cache">cache behavior</a>.</p></Accordion>
      <Accordion title="How do I refresh project discovery?"><p>After editing project definitions or changing which projects ignore rules include, run <code>isox reset</code> before a single-project command. Source and import edits do not require reset. Affected selection, planning, and run-many refresh definitions automatically; dependency requests validate their own cache. Stop active builds before resetting because it also clears TypeScript build state.</p></Accordion>
