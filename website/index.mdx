    <div className="home-faq-list">
      <Accordion title="Do I need to change my build tools?"><p>No. The bundled shell executor runs your existing commands. Add native plugins project by project where they fit your workflow.</p></Accordion>
      <Accordion title="Can I use Isox without TypeScript?"><p>Yes. Define projects with <code>project.json</code> and run any CLI through the bundled shell executor. TypeScript is optional. <a href="/docs/shell-commands">Wrap an existing script</a> to start.</p></Accordion>
      <Accordion title="Can Isox reuse task results?"><p>Yes. Native targets can opt into <a href="/docs/task-caching">local task caching</a> with <code>cache: true</code>. Matching inputs reuse a successful result, replay logs, and restore declared outputs. Remote caching remains on the roadmap.</p></Accordion>
      <Accordion title="Does Isox build prerequisites automatically?"><p>Yes, when you declare them with <code>dependsOn</code>. Use <code>["^build"]</code> to build dependencies first, or <code>["build"]</code> to run a build before tests in the same project. Each CI worker expands its own prerequisites. See <a href="/docs/task-prerequisites">task prerequisites</a>.</p></Accordion>
      <Accordion title="Can I move from Nx gradually?"><p>Yes. Move targets to shell commands or native plugins project by project. An optional adapter can temporarily run supported Nx 23 executors. Start with the <a href="/docs/nx-migration">migration guide</a>.</p></Accordion>
