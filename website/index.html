01 / DEFINE

Explicit by design.

Each project has a project.json. Its name, commands, dependencies, and tags live together, right where the project does.

02 / DISCOVER

A workspace that stays simple.

An isox.json marks your workspace root. Isox discovers your projects and caches their configuration locally. No background daemon needed.

03 / RUN

Your command, your way.

Run your existing scripts with the bundled shell executor, or write a native executor with access to your project and workspace context.

Requires Node.js 24+.

  1. 1

    Install & initialize

    Run these commands at the root of your workspace.

    npm install -D isox
npx isox init
  2. 2

    Define your project

    Save the example above as apps/web/project.json, in a project with an existing build npm script.

  3. 3

    Run with Isox

    npx isox build web

    Changed a project configuration? Run npx isox reset to refresh discovery on the next run.
