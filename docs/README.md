# Isox documentation

Isox discovers projects and runs commands defined in their `project.json` files.
Start with the setup guide, then use the topic references for your workspace.

- [Migrating from Nx](nx-migration.md) — project conversion and temporary Nx 23 adapter support.
- [AI migration prompt](prompts/migrate-nx-to-isox.md) — a reusable prompt for migrating an existing Nx workspace.
