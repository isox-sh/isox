# @isox-sh/eslint

ESLint executor for Isox.

```sh
npm install --save-dev @isox-sh/eslint
```

Use `eslint:lint` or `@isox-sh/eslint:lint` in your project's `targets`.

See the [ESLint executor guide](https://github.com/isox-sh/isox/blob/main/website/docs/eslint.md)
for configuration and options.
